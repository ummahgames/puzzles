# Lantern Links

A pixel-art lantern garden with fresh generated puzzles, continuous path drawing, animated colored ribbons, and numbered lanterns. No fixed eight-level campaign or level-selection page: choose a challenge and start an evening.

## Rules and controls

Connect every matching pair and fill every tile. Paths move horizontally or vertically, cannot cross, and cannot pass through another pair’s endpoint. Start from either lantern. Drag backward to shorten a path; grab an existing path midway to edit it, or start at its lantern to redraw. Tap a lantern and then adjacent tiles for tap-to-draw.

Keyboard: Tab into the garden, use arrows to explore, Space/Enter to begin, then arrows to draw. Escape lifts your pencil; Z undoes the last stroke. Numbered endpoints and labeled pair buttons identify colors. Undo keeps 100 recent strokes. Reset paths repeats the current layout. Peek shows one complete solution for ten seconds without changing your paths.

## Generation and difficulty

Every offered board is generated by `lantern-core.js`. A Hamiltonian snake is mixed using randomized endpoint reversals (backbite moves), then partitioned into disjoint routes. Candidate scoring favors bends and penalizes neighboring pair endpoints. An independent certificate validator checks endpoint identity, bounds, adjacency, uniqueness, and complete grid coverage before a board is offered. Tests also replay certificates through the same drawing rules used in play.

The four tiers start with:

| Tier | Initial grid | Initial pairs | Automatic progression |
| --- | --- | --- | --- |
| Easy | 2 × 2 | 1 | Grows to 3 × 3, staying at one pair |
| Medium | 3 × 3 | 2 | Grows to 4 × 4 and three pairs |
| Hard | 4 × 4 | 3 | Grows to 5 × 5 and four pairs |
| Expert | 5 × 5 | 5 | Grows to 9 × 9 and nine pairs |

Automatic grids grow every four evenings until that tier’s cap. Candidate scoring also targets progressively more route bends from Easy to Expert, including when custom dimensions and pair counts are fixed. You can choose any size from 2 × 2 to 9 × 9 and one to nine pairs; pair counts are capped by grid capacity so each generated route has at least three tiles. Difficulty is a size/pair/bend heuristic, not a proof of human solving difficulty or a unique solution. Alternative valid solutions count.

Both grid axes use explicit equal tracks, independent of whether cells contain lantern sprites. The SVG overlay stretches to those same grid bounds, keeping drawn routes and solution peeks centered on every tile.

Next evening generates another board. New layout rerolls the current evening. Restart keeps the current board. Each generation uses a fresh random seed; there is no finite authored campaign in this interface.

## Saving

Keep my place exports a bounded `LL3` preferences code in the URL. It stores challenge, preferred size, preferred pair count, and evening number. Loading or reloading generates a fresh solvable board at those settings. Neither the seed, exact board, nor partial paths are saved. Older LL2 codes still load: Gentle maps to Easy, Thoughtful to Medium, and Tricky to Hard, retaining explicit grid/pair preferences and evening number. No local storage, backend, or network service is required. The old shared engine remains in the toolkit for compatibility tests; the new page uses the dedicated Lantern runtime.

## Display and accessibility

Standalone local assets, responsive phone/tablet/desktop layout, shared fullscreen controls, reduced-motion preference and Quiet animation toggle, optional synthesized chimes, keyboard drawing, labeled tiles, and numbered color pairs. Current progress is announced without a ticking clock or lives.

## Development

Canonical files: `../../game-kit/lantern-page.html`, `lantern-core.js`, `lantern-game.js`, `lantern.css`, and this generated README source `lantern-readme.md`. Run `node game-kit/build.cjs` from the workspace root to distribute. Run `node game-kit/test.cjs` for all suites, or `node --test game-kit/tests/lantern.test.cjs` for generator, rules, input interpolation, preference codes, and distribution checks.
